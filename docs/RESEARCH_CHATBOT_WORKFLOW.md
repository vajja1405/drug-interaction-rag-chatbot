# Medication evidence review workflow

Intended user: a medication-information researcher or trained reviewer evaluating
retrieval coverage. This educational prototype has no demonstrated patient adoption.

1. Enter medication names using search suggestions. Brand names, spelling mistakes,
   combination products, and unsupported names still need explicit confirmation.
2. Review research labels, linked evidence, method, and unavailable-model status.
3. Download the research review summary to preserve the query, evidence version,
   method and source links. It deliberately does not export generated treatment instructions.
4. Ask a qualified reviewer to resolve ingredient ambiguity and unsupported evidence.
5. Record label correctness, source correctness, abstentions, time to find evidence,
   and corrections in a controlled pilot before considering clinical use.

Changing selected medication names now invalidates the displayed result, preventing
a stale result from being mistaken for the new medication list. No clinical outcomes,
user adoption, or new accuracy improvements were measured in this update.
